## 8. Risks and surprises

- **The terrain pass has been tinting the map with a pack PNG since #50, and no doc said so.** The mechanism: one texture — the first terrain-class entry in BTreeMap (class-id) order, else the first entity entry — stretched over the map extent (world-space UV, ClampToEdge) and multiplied into the procedurally-lit terrain. With no pack (and whenever the first entry fails to open) the 1×1 white fallback makes it a no-op. What I could **not** verify here: which PNG the *official* pack's manifest puts first (the assets repo was not fetched in this environment — the mechanism is code-verified, the official manifest's key order is not). If the tactical_field look was tuned expecting no tint, that is an owner's-eyes question, not a code bug — flagged, not fixed, per the brief's STOP discipline.
- **The ADR's proposal-time tense** ("cannot yet load", "Not yet — placeholder used", "render placeholders today") stays by design — dated record, one-paragraph cap — but a skimmer could misread it; §9 P3 proposes the light fix for a future ADR-touching brief.
