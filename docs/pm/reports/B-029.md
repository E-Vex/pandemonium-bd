**The cause is re-labeling, not behavior** — the derivation:

1. Entity files load in filename sort; `ballista.ron` sorts before
   `barracks.ron`, so every existing kind's positional KindId shifts
   (barracks 0→1, command_center 1→2, ..., worker 8→12).
2. `sim/src/hash.rs` writes `entity.kind.0` into the canonical state —
   every content-anchored hash moves from tick 0 onward, identically on
   every OS (the encoding is little-endian, platform-independent).
3. **Behavior is proven bit-identical**: the flagship run over the new
   content reports the same **612 commands** and the same per-player
   counters (deliveries 478/572, trained 22/24, built 3, hits 183/260,
   deaths 6/9) as master's registered run; and the four controller
   **RNG-stream baselines** in `tests/mission_ai.rs` — the behavior
   anchors written by B-021 exactly for this kind of question — held
   **bit-identical without edit** (only the final-hash and wire-digest
   pins moved; the digest covers the replay wire bytes, which carry
   KindIds by design).
4. The demo golden never moved (the trivial world ignores content —
   verified live).

**The lesson is registered**: AI-Handoff §9 now carries the KindId
re-labeling gotcha, and the assumption A-223 records the producers-map
sort invariant. A proposal for kind-id stability is filed (§9 below), NOT
implemented — it would be an encoding change, exactly the frozen-decision
territory an ADR exists for.

## 9 Proposals (not implemented)

- **Kind-id stability across content growth** (from §5's lesson): either
  name-derived kind ids (a hashed name → id map, stable under growth) or
  an explicit kind registry file. Either changes the state encoding or
  the loader contract — frozen-decision territory (FD territory, plan
  §2/§6.4), so it is a PM/owner decision with an ADR, not a rider on a
  content pass. Until then, the authorized-move procedure + the RNG
  behavior anchors make each growth pass's re-pin safe and cheap (this
  pass is the worked example).
- **The scripted AI's adoption of the second tier** (fielding the Forge
  when ahead, Lancers into Guardian-heavy reads): a script-extension
  brief would move the flagship golden under the same procedure; the
  §19 step 8 evaluative-AI arc is the principled home. Not started here
  — the additive pass's whole point was that the opponent stays
