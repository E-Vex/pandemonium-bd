## 1. Summary

ADR-0201's Phase 1 vertical slice is implemented from the authoritative side. A
mission is now a versioned content file — `content/missions/<id>.ron`, strict
`deny_unknown_fields`, `schema_version` 1, the forward-only gate — a closed
reference set into the content tree (map + faction + rules, all validated at
load) plus an ordered, AND-composed objective list in the two Phase 1 kinds:
Destroy (all enemy structures, or a target kind) and BuildTrain (N entities of a
kind, optional). The mission carries its own domain-separated identity — the
`MAP_ID_DOMAIN` pattern with the word `0x004d_4953`, computed over a canonical
mission encoding that appends **nothing** to the existing content-hash or map-id
byte paths, so the registered goldens cannot move (proven live, §5). Stage 10
generalizes over an optional objective set: mission-less, the evaluator is
exactly today's elimination rule — byte-for-byte (the proof test and its output,
§3.3); with a mission loaded, each objective resolves per tick (monotonic, one
outward `Event::ObjectiveState` each), the AND-composition ends the match
(mission player wins when every non-optional objective completes; the opponent
wins when one fails), and the elimination rule stays live beneath it. Replays
gained the optional `mission_id` header field (FORMAT_VERSION 1 → 2, forward-only,
not a golden — no replay file is committed), and `verify_replay` gained the third
identity comparison. The sim's mission seam is `Sim::with_mission(world, setup,
objectives)` — construction-time, FD-6-clean: mission data reaches the sim only
through the content seam (`ContentTree::mission_objectives` resolves kind-id
strings to `KindId`s in the tree's entity order).

  (the AND-composition requires at least one non-optional objective; elimination

  non-mission player in world order (`opponent_of`), `NEUTRAL` in the degenerate

  fire on the same tick, objectives run first — a mutual-destruction tick on
  which the mission player's destroy objective also completes resolves as a

  unknown id returns the documented `0` sentinel (real ids hash the domain word
  first).
