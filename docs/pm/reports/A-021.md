## 8 Risks and surprises

- **naga 30's integer-interpolate rule** was the only test-visible
  behavior change: the entity shader's `u32` skin varying now declares
  `@interpolate(flat)` (a spec-compliance enforcement, not a semantic
  change — flat is what integer varyings always meant; the other five
  shaders validate unchanged).
- **The display-handle requirement is load-bearing, not cosmetic:**
  wgpu 29 moved the display from the surface to the instance, and GLES
  presentation *requires* it — the Xvfb/GL evidence path (and Wayland
  real machines) would break with the handle-less constructor. The
  windowed renderer now takes the event loop's `OwnedDisplayHandle`
  explicitly (§9's new gotcha records the law for future
  instance-creation sites).
- **CI's cross-OS legs** (windows-2025, macos-26) could not run in this
  sandbox — the PR's CI run is that evidence, watched to green before
  this report's "done" claim (Standing Orders §8: the run URL rides the
  PR). The historical Windows client-crash class (WINDOWS_CI_CRASH.md,
  closed at a2bc546) is unrelated to a version bump that does not touch
  the audio stack — rodio/cpal are byte-identical versions — but the
  legs were watched anyway.
- The verification host: 2-core sandbox, Debian trixie userland, Mesa
  25.0.7 llvmpipe, Xvfb 21.1.16 — the §9 recipe verbatim, with the
  a010 script's own bootstrap building the userland EGL tree.
