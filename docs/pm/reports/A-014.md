The diff is cosmetic (2 re-wraps) and mechanical to fix, but that is a separate, dedicated commit (§9 P1) — doing it inside A-014 would have exceeded the touch list.

- The smoke now hard-requires the pack (§3.2 gates). If the assets repo is ever renamed/made private, release legs fail at the checkout or the pack gate — an intentional tripwire, called out here so the failure mode is not a surprise.
