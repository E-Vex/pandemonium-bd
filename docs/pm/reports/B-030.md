## 8 Risks and surprises

- The dev soak tier command as written in AI-Handoff §4
  (`soak --matches 4 --ticks 900`) exits nonzero at that tier (4
  unresolved — 900 ticks is under any resolution time). **Pre-existing on
  master** (re-verified on a pristine HEAD worktree: identical output);
  that tier's value is the A12 invariant sweep + crash isolation, which
  pass (0 crashed). Not a regression; noted because the §4 text reads as
  if the command ends green.
- The map file is 29,886 bytes (72 heightmap rows of 72 u16s) — between
  Crossroads' 24KB and Verdant Frontier's 30KB; no repo machinery cares
  (the loader, packager, and release archive all treat maps as opaque
  data).
- The basin resolves *inside* the flagship's own budget class (tick
  11956 at seed 7; the crossroads soak average is 14337) — the bigger
  field did not stall the scripted opponents, which was the one real
  gameplay risk of a 72-wide lane map (ore the workers cannot path to, or
  lanes the armies cannot walk, would have shown up as non-resolution;
  it did not).
